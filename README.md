# Trailhead

Find hiking trails near you, check the climb before you go and keep the map when the
signal drops.

## Features

- Trails sorted by how far away they start
- Elevation profile with the climb for every section
- Offline maps downloaded per trail
- Difficulty badge for every trail
- Search and filter by difficulty

## Building

Requires Xcode 26 and iOS 18. Trail data lives in `Trailhead/Resources/trails.json`.
